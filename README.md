# 하노이 선교교회 홈페이지 초안

## 실행 방법
`index.html`을 Chrome 또는 Edge에서 열면 됩니다.

## 포함 기능
- 한글/베트남어 즉시 전환
- PC·태블릿·모바일 반응형 구성
- 교회 소개 및 4대 비전
- 실제 예배 시간표
- YouTube 새 영상 자동 업데이트 미디어 허브
- 유튜브 추천 설교 3편 연결
- 목사님 Instagram 계정 연결, TikTok·Zalo 연결 준비 카드
- 다음세대·찬양·공동체 소개
- 새가족 및 하노이 방문 안내
- 선교와 나눔 및 선교후원 안내 (계좌 정보는 미게시)
- 별도 자료실 `archive/`: 검색·분류·12건씩 페이지 나누기, 열람·다운로드
- 관리자 GitHub 업로드 후 공개 파일 목록 자동 갱신 (주보 PDF 12개 등록)
- 예배 PPT에서 추출한 컬러 교회 엠블럼
- Google Maps, 전화, 이메일 연결

## 게시 전 확인 권장사항
1. 베트남어 번역을 베트남 성도 또는 전문 번역자가 최종 감수
2. 담임목사 공식 인사말과 프로필 사진 추가
3. 교회 외관, 본당, 다음세대, 식사 친교, 선교 현장 사진 추가
4. 현재 엠블럼은 예배 PPT에서 추출한 작은 이미지입니다. 고해상도 원본을 받으면 교체 권장
5. 공지사항과 주보를 누가 어떤 방식으로 갱신할지 결정
6. 교회 명의로 최종 검토 후 공개
7. TikTok·Zalo 공식 계정 개설 후 주소 연결

자세한 관리 방법은 `SNS-운영안내.md`를 참고하세요.

## 자료실 관리 방법
- [자료실](https://djkang1004.github.io/hanoi-mission-church-draft/archive/)의 **관리자 업로드 (GitHub)** 버튼에서 GitHub 로그인 후 파일을 선택하고 `Commit changes`를 눌러 저장합니다. 저장소 쓰기 권한이 있는 계정만 가능합니다. 사이트에 암호나 토큰을 입력하지 않습니다.
- 분류별 폴더: `assets/bulletins/` (주보), `assets/library/notices/` (교회소식), `assets/library/study/` (교육자료), `assets/library/mission/` (선교자료), `assets/library/other/` (기타).
- 주보는 `YYYY-MM-DD.pdf` 형식으로 저장하면 날짜 기준으로 정렬됩니다. 다른 자료도 파일명에 `YYYY-MM-DD`를 넣으면 날짜로 정렬됩니다. 이름이 같은 파일은 덮어쓰기될 수 있으니 주의합니다.
- 저장 후 몇 분 뒤 자료실의 **새 자료 확인**을 누르면 GitHub 공개 파일 목록에서 자료를 불러옵니다. 방문자 브라우저는 5분 동안 목록을 캐시합니다. GitHub API에 일시적으로 연결할 수 없으면 이전 목록 또는 최초 12개 주보를 표시합니다.
- GitHub Pages는 정적 사이트입니다. 이 방식은 **자료실 페이지 안에서 직접 파일을 보내는 업로드 양식이 아니라 GitHub의 권한 있는 업로드 화면으로 이동**하는 방식입니다. 사이트 안에서 업로드하려면 별도의 인증·저장소 서버가 필요합니다.
- 이 저장소는 공개 저장소입니다. 개인정보, 개인 연락처, 계좌 등의 공개 적합성을 검토한 뒤 올립니다. 기존 10월 18일 PNG 이미지는 예전 링크 호환을 위해 남겨두었습니다.
