# 하노이 선교교회 홈페이지 초안

## 실행 방법
`index.html`을 Chrome 또는 Edge에서 열면 됩니다.

## 포함 기능
- 한글/베트남어 즉시 전환
- PC·태블릿·모바일 반응형 구성
- 교회 소개 및 4대 비전
- 실제 예배 시간표
- YouTube 새 영상 자동 업데이트 미디어 허브
- 유튜브 추천 설교 3편 연결
- 목사님 Instagram 계정 연결, TikTok·Zalo 연결 준비 카드
- 다음세대·찬양·공동체 소개
- 새가족 및 하노이 방문 안내
- 선교와 나눔, 주보에 근거한 선교후원 안내 (계좌 정보는 미게시)
- 자료실: 2026년 10월 18일 주보 이미지 열람·다운로드
- 예배 PPT에서 추출한 컬러 교회 엠블럼
- Google Maps, 전화, 이메일 연결

## 게시 전 확인 권장사항
1. 베트남어 번역을 베트남 성도 또는 전문 번역자가 최종 감수
2. 담임목사 공식 인사말과 프로필 사진 추가
3. 교회 외관, 본당, 다음세대, 식사 친교, 선교 현장 사진 추가
4. 현재 엠블럼은 예배 PPT에서 추출한 작은 이미지입니다. 고해상도 원본을 받으면 교체 권장
5. 공지사항과 주보를 누가 어떤 방식으로 갱신할지 결정
6. 교회 명의로 최종 검토 후 공개
7. TikTok·Zalo 공식 계정 개설 후 주소 연결

자세한 관리 방법은 `SNS-운영안내.md`를 참고하세요.

## 주보 자료실 갱신 방법
1. 새 주보 이미지를 `assets/bulletins/YYYY-MM-DD.png` 이름으로 저장합니다.
2. `index.html`의 `#archive` 섹션 안에 기존 `<article class="archive-item">`을 복사하고 날짜·호수·파일 경로·설명을 새 주보에 맞게 바꿉니다. 새 주보를 앞에 추가하면 최신순으로 보입니다.
3. 개인 연락처, 계좌 등 공개하면 안 되는 내용이 없는지 확인한 뒤 GitHub에 커밋·푸시합니다.

현재 자료실은 정적 목록이며 자동 업로드 기능은 없습니다.
