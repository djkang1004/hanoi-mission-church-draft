# 하노이 선교교회 홈페이지 초안

## 실행 방법
`index.html`을 Chrome 또는 Edge에서 열면 됩니다.

## 포함 기능
- 한글/베트남어 즉시 전환
- PC·태블릿·모바일 반응형 구성
- 교회 소개 및 4대 비전
- 실제 예배 시간표
- 유튜브 최신 설교 3편 연결
- 다음세대·찬양·공동체 소개
- 새가족 및 하노이 방문 안내
- 선교와 나눔 소개
- Google Maps, 전화, 이메일 연결

## 적용한 확인 자료
- 2026년 10월 11일 교회 주보
- 2026년 10월 11일 주일예배 PPT
- 하노이선교교회 NotebookLM 자료
- 하노이선교교회 YouTube 채널
- Google Maps 교회 정보
- 카카오톡 받은 파일 내 디아코니아 중창단 사진

## 게시 전 확인 권장사항
1. 베트남어 번역을 베트남 성도 또는 전문 번역자가 최종 감수
2. 담임목사 공식 인사말과 프로필 사진 추가
3. 교회 외관, 본당, 다음세대, 식사 친교, 선교 현장 사진 추가
4. 교회 로고 원본 파일로 현재 임시 심벌 교체
5. 공지사항과 주보를 누가 어떤 방식으로 갱신할지 결정
6. 교회 명의로 최종 검토 후 공개
