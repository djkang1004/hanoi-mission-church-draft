관리자: 자료 올리는 방법

초대받은 WordPress 계정으로 로그인하세요. 전체관리자는 사람과 권한을 관리하고, 편집자는 자료 글과 미디어를 관리합니다. GitHub 계정은 필요하지 않습니다.

  1. 미디어 라이브러리에 공개 가능한 PDF, 사진 또는 설교 PPTX를 올립니다. 설교 PPT는 일반 교인이 웹에서 열람할 수 있으므로 공개 가능한 자료만 올리세요.
  2. 새 글을 만들고 제목에 날짜를 넣은 뒤 주보·설교PPT·교회소식·교육자료·선교자료·기타자료 중 하나를 선택합니다.
  3. 글 본문에 업로드한 파일 링크를 넣고 미리보기를 확인한 다음 공개합니다. 공개된 글만 자료실에 표시됩니다.
  4. 수정·삭제는 모든 글에서 처리하고, 이 페이지의 ‘새 자료 확인’을 누르면 목록이 갱신됩니다.
새 자료 등록자료 수정·삭제사용자 권한 관리 (전체관리자)

중요: WordPress 미디어 파일은 공개 열람용입니다. 공개하면 안 되는 개인정보·계좌정보·내부자료는 업로드하지 마세요. 자료를 내릴 때는 글뿐 아니라 미디어 파일도 함께 삭제해야 합니다.
